# ADR 0004: Use GitHub as the project source of truth

- Status: Accepted
- Date: 2026-10-07

## Context

The project will be developed through issues, feature branches, focused commits, and pull requests, often with coding agents.

## Decision

Track scope and delivery in GitHub Issues and Pull Requests. GitHub Projects may be used as a view. Use Conventional Commits and repository-local templates.

## Consequences

No separate task management service or custom BMAD clone is introduced. Product discovery artifacts remain plain documentation until workflow tooling is selected.
