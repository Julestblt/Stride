# Agent responsibilities

Agents are specialized actors selected by an orchestrator. Each has a narrow responsibility, declared inputs, allowed tools, and structured output. An agent is not a folder of prompts and is not interchangeable with a skill.

## Planned roles

- **Stride Coach / Orchestrator:** understand the request, choose a safe workflow, delegate to specialists, and synthesize the result.
- **Training Coach:** interpret goals and training history to recommend or adjust training structure.
- **Performance Analyst:** analyze activity and fitness trends, explain evidence, and state uncertainty.
- **Recovery Specialist:** interpret readiness and recovery signals and advise on training modifications.
- **Race Strategist:** translate athlete and course context into race goals, pacing, fueling, and contingencies.

The roles above describe future responsibilities. They are not implemented agents. Specialists should not independently change athlete data or bypass application authorization.
