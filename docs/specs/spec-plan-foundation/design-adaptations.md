# Plan screens design adaptations

The approved references in `design/references/app/plan` and `design/references/app/workout-detail` remain the visual source of truth. These adaptations apply only where Phase 1 data or an accepted product decision cannot support the mockup.

| Screen         | Mockup element                                                                               | Implementation                                                                                                                            | Reason                                                                                       |
| -------------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Plan           | "Blocs" group in the application sidebar                                                     | Block and week navigation inside the page: a left column on wide screens, "Toutes les semaines" below on smaller ones                     | The draft is computed per request; building it on every application page would be too costly |
| Plan           | Command bar "Déplacer, échanger, raccourcir…", "Changements de la semaine", compliance marks | Hidden                                                                                                                                    | No proposals or matching yet (#103, #104, Phase 4)                                           |
| Plan           | "Jours de repos masqués · afficher" toggle                                                   | A single "Repos : lun., ven." line                                                                                                        | Rest days carry no content in the draft                                                      |
| Plan           | Status column "PRÉVU", "98 % ✓", "EXAMINER"                                                  | "Prévu" for sessions, "Course" for race days                                                                                              | No completion data or pending proposal                                                       |
| Plan           | Weekly D+ statistic                                                                          | Shown only when the week has elevation targets                                                                                            | Road plans carry no elevation                                                                |
| Plan           | No draft notice                                                                              | "Brouillon calculé par Stride…" banner on every plan screen, plus feasibility and validator "Points d’attention"                          | Phase 1 shows an unsaved deterministic draft (FR-30)                                         |
| Workout detail | "Envoyer sur Garmin", "Remplacer la séance", proposed-version banner                         | Hidden                                                                                                                                    | Garmin push is deferred (D5); no proposals yet                                               |
| Workout detail | "Tes habitudes", "Repères", nutrition, shoes, best moment                                    | Hidden                                                                                                                                    | No data source in Phase 1                                                                    |
| Workout detail | "Pourquoi cette séance" written for this athlete                                             | The block's name and objective                                                                                                            | Explanations come from the Coach model (Phase 3)                                             |
| Workout detail | Pace and heart-rate ranges side by side on every step                                        | One target per step (pace on road, heart rate on trail, effort without calibration); the other signal is in the cue and the session stats | The session structure carries one watch-compatible target per step                           |
