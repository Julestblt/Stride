- (direction) The approved PNG files in design/references/system are the visual source of truth; production code expresses their intent with Stride architecture, Tailwind, accessible shadcn primitives, and no copied mockup markup.
- (decision) Night Track uses Shell #080907, Inset #0C0D0B, Surface #131411, Raised #1A1B18, Chalk #EDECE6, and scarce Volt #D5FF3F; use named semantic roles for secondary text, borders, provider provenance, and status.
- (decision) Load Barlow Condensed for large numeric metrics, Instrument Sans for interface/body/coach text, and IBM Plex Mono for labels and technical metadata through Next.js font optimization.
- (constraint) Expose reusable semantic CSS variables and Tailwind tokens for page background, foreground, surfaces, borders, muted text, accent, success, warning, danger, and focus; components must not scatter raw color literals.
- (constraint) Global controls and motion defaults must provide visible focus, disabled, invalid, skeleton, and reduced-motion behavior without adding a full application shell or decorative animation.
- (capability) CAP-1: The application can apply a coherent Night Track global theme; success: global tokens map to the approved palette, semantic typography roles use the three approved fonts, and form/state/motion styles remain usable with keyboard focus and reduced motion.
- (note) The reusable-pattern reference also establishes design intent for sidebar context, provenance labels, sync states, recommendation cards, approval controls, metric verdicts, and mobile navigation; these are not screens to implement in the theme slice.
- (event) Inputs and boundaries were reviewed against the approved reference images, current CSS/Tailwind 4 setup, Next.js font guidance, and the focused theme issue scope.
- (event) Coherence validation passed: the two capabilities each have an intent and observable success condition; constraints change implementation choices; explicit non-goals cover product screens and dependencies; the success signal is verifiable through screenshots and repository checks.
- (event) Preservation validation passed: visual direction, palette, typography, semantic tokens, global states, reduced motion, no-shell boundary, responsive/reference policy, and reusable-pattern context are represented in the spec or its companions; process-only ceremony was omitted.
