# Onboarding design adaptations

The approved references in `design/references/onboarding/**` remain the visual source of truth. These adaptations apply only where the real API or an accepted product decision cannot support the mockup. Keep layout, hierarchy, tone and component language unchanged.

| Screen          | Mockup element                                                                                                       | Implementation                                                                                                                                         | Reason                                                                        |
| --------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| Import history  | Category percentages, `/ ~2 480` totals, "dans 8 minutes environ"                                                    | Category state labels, verified activity count, oldest synchronized date ("Actuellement : mars 2021")                                                  | garmin_mcp reports no totals, percentages or estimates                        |
| Import history  | Year timeline                                                                                                        | Last nine years, extended back to the oldest synchronized year and trimmed to it once complete; filled from today back to the oldest synchronized date | garmin_mcp does not expose the connection floor; derived only from real dates |
| Import history  | "Ce que je remarque" insights                                                                                        | Omitted                                                                                                                                                | Generated insights are deferred                                               |
| Import history  | "Je te préviens quand tout l'historique est là", "Tu peux fermer l'appli. On te prévient…"                           | "La lecture continue en arrière-plan pendant que tu avances." / "Tout l'historique disponible est lu."                                                 | Import notifications are out of scope                                         |
| Import history  | "Données partielles" (watch without HRV)                                                                             | Shown when garmin_mcp reports a failed category; "Import en pause" on reconnect; "Garmin est lent" when polling fails                                  | Only states garmin_mcp actually reports                                       |
| Shell           | Sidebar import card with percentage bar                                                                              | State label, indeterminate activity indicator while running, activity count and current year                                                           | No real percentage exists                                                     |
| Shell           | Sidebar line "Lecture en cours · 71 %"                                                                               | "Lecture en cours · <année>"                                                                                                                           | No real percentage exists                                                     |
| Connect Garmin  | `invalid_mfa` returns to code entry with the code selected                                                           | Code-not-accepted notice, then "Se reconnecter" back to the credentials form with the email kept                                                       | garmin_mcp consumes the challenge on an invalid code                          |
| Connect Garmin  | `rate_limited` countdown "Réessayer dans 4:52"                                                                       | Pause message without countdown; countdown only when garmin_mcp returns retry timing                                                                   | No retry timing in the current contract                                       |
| About you       | "Déjà connu" panel and Garmin-sourced weight                                                                         | Shown only for values garmin_mcp provides; otherwise the panel lists none and fields are entered by the athlete                                        | Profile and biometric import not available yet                                |
| About you       | Terrain suggestion "68 % de ta dernière année en trail"                                                              | Shown only when computed from imported activities with the stated window; otherwise omitted                                                            | Must reflect real data                                                        |
| Goals           | "Trouvée dans ton calendrier Garmin", "Importer le GPX du parcours"                                                  | Omitted                                                                                                                                                | Calendar lookup and GPX upload are deferred                                   |
| Athlete profile | Threshold pace, climbing speed, 10 km prediction, heart-rate zones, finish estimate, habits, recovery after an ultra | Omitted or marked unavailable                                                                                                                          | Stride predictions are deferred                                               |
| Athlete profile | Activity and history totals, weekly volume, resting heart rate, HRV, sleep, VO2 max                                  | Shown from normalized garmin_mcp rows with their window and source, or as missing                                                                      | Real data only                                                                |
