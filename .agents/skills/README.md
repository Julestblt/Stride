# Installed BMAD skills

These Codex skills are copied from the official [BMAD Method repository](https://github.com/bmad-code-org/BMAD-METHOD) with the official Skills CLI. The installed modules are core-tools and method; their versions and source paths are recorded in the repository-level skills-lock.json.

Run npx skills update -p -y to update the copied skills, then ask the bmad skill to run setup. Do not edit upstream skill files directly. Add or remove skills through the official CLI and update this lock file with it.
